## 🚀 О расширении

**Crypto Auto Filler** - это два инструмента в одном расширении:

1. **Автозаполнение полей** - экономит время при рутинном вводе сумм и сохраняет возможность быстрого набора позиции частями
2. **Расчет спреда** - расчитывает спред на требуемую пару между двумя биржами

📌 **Главное преимущество**: Вы получаете данные о спреде **сразу при листинге** новой монеты!


## ✨ Почему это удобно?

### Для арбитража:
- ⚡ **Данные каждые 0.5 секунды** - Достаточно актуальная информация
- 🎯 **Точный расчет** на основе лучших цен в стаканах ордеров
- 🚀 **Работает с момента листинга** - ловите возможности первым

### Для обычной торговли:
- ⏱️ **Экономия времени** - больше не нужно вручную вводить суммы
- ✅ **Защита от ошибок** - автоматическое заполнение правильных значений (введенных вами в расширение)
- 🛡️ **Безопасность** - не используются и не собираются ваши персональные данные

## 💻 Как это работает?

1. **Выбираете две биржи** из поддерживаемых (MEXC, Gate, Bitget, KuCoin)
2. **Вводите название токена** (только USDT-пары)
3. **Нажимаете "Старт"**
4. **Видите два значения**:
   - 📈 **Спред входа** - разница при покупке на 1-й и продаже на 2-й бирже
   - 📉 **Спред выхода** - разница при обратной сделке

## ⚙️ Технические детали

- 🔄 **Обновление данных**: каждые 0.5 секунды через REST API
- 📊 **Формула расчета**:
  ```javascript
  Спред входа = ((Цена bid на 2-й бирже - Цена ask на 1-й бирже) / Цена bid на 2-й бирже) × 100%
  Спред выхода = ((Цена ask на 2-й бирже - Цена bid на 1-й бирже) / Цена ask на 2-й бирже) × 100%
  ```

## ⚠️ Ограничения:

- Только USDT-пары
- Одновременно можно сравнивать только одну пару бирж
- Если данные недоступны - отображается "NaN"


## ⚙️ Установка

#### Установка из исходного кода

1.  **Скачайте код:**  Склонируйте репозиторий или скачайте ZIP-архив:

    ```bash
    git clone https://github.com/SamuelGambino/Crypto-Auto-Filler.git
    ```

2.  **Установите расширение:**

    *   **Google Chrome:**
        1.  Откройте `chrome://extensions/`.
        2.  Включите "Режим разработчика" (Developer mode).
        3.  Нажмите "Загрузить распакованное расширение" (Load unpacked).
        4.  Выберите папку с кодом расширения.

    *   **Mozilla Firefox:**
        1.  Откройте `about:debugging`.
        2.  Нажмите "Этот Firefox" (This Firefox).
        3.  Нажмите "Загрузить временное дополнение" (Load Temporary Add-on).
        4.  Выберите файл `manifest.json` в папке с кодом.

## 📖 Использование

1.  **Откройте окно расширения:** Нажмите на иконку расширения Crypto Auto Filler на панели инструментов браузера.
2.  **Введите значение:** Введите желаемое количество монет в поле ввода.
3.  **Сохраните:** Нажмите кнопку "Сохранить".

Теперь расширение будет автоматически заполнять поля ввода количества монет на поддерживаемых биржах.

3.  **Введите токен:** Введите название токена в полке "Введите токен:".
4.  **Выберите биржи:** Выберите две биржи, межу которыми нужно расчитать спред, левая биржа для long позиции, правая для short.
5.  **Нажмите страрт:** Нажмите кнопку "Страрт".

Теперь расширение будет автоматически расчитывать спред между выбранными биржами.


## ⁉️ Устранение неполадок

*   **Расширение не заполняет поле:**
    *   Убедитесь, что вы находитесь на поддерживаемой бирже.
    *   Проверьте, что вы ввели и сохранили значение во всплывающем окне расширения.
    *   Перезагрузите страницу.
    *   Проверьте консоль разработчика (F12) на наличие ошибок.
    *  Проверьте, что поле для ввода имеет `type="text"` :).
*   **Расширение не расчитывает спред:** 
    *   Убедитесь, что вы биржи выбраны и эти пары существуют на этих биржах.
    *   Перезапустите расчет спреда, нажмите "Стоп", убедитесь в отсутствии опечаток и снова нажмите "Старт".
